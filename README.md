# nexoniarz-config-nixos-laptop

My personal NixOS system configuration tailored for daily use on an
**ASUS TUF Gaming A15 (FA507NU)**.

## Overview

- **OS:** NixOS
- **DE / Compositor:** Pantheon (gala, Wayland)
- **Display manager:** LightDM (elementary greeter)
- **Shell:** Zsh
- **CPU:** AMD Ryzen 5 7535HS
- **GPU:** AMD Radeon 680M (iGPU, drives the internal panel) + NVIDIA RTX
  4050 Max-Q (dGPU, PRIME render offload only — run anything through it with
  `nvidia-offload <command>`)
- **Laptop control:** `asusctl` (fan curves, keyboard backlight, battery
  charge limit) + `supergfxctl` (dGPU power-state switching)

## Layout

- `configuration.nix` — top-level imports
- `hardware-configuration.nix` — generated by `nixos-generate-config`, don't
  hand-edit
- `modules/system.nix` — bootloader, networking, time, sound, hardening,
  nix-ld
- `modules/drivers.nix` — hybrid graphics (NVIDIA PRIME offload), ASUS
  daemons, misc hardware (webcam loopback, tablet driver)
- `modules/desktop.nix` — Pantheon desktop environment
- `modules/users.nix` — user account, Steam, Firefox, Flatpak
- `modules/apps.nix` — all installed packages
- `modules/scripts.nix` + `modules/scripts/` — small custom CLI helpers
  (encrypted vault toggle, metadata stripping, brightness control, Wi-Fi
  hotspot, system telemetry, weather fetch)
