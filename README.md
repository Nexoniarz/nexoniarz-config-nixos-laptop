# nexoniarz-config-nixos-laptop

My personal NixOS system configuration tailored for daily use on an
**ASUS TUF Gaming A15 (FA507NU)**. Same layout and same choices as
[nexoniarz-config-nixos](https://github.com/Nexoniarz/nexoniarz-config-nixos)
(the desktop), with the hardware and power modules swapped for this machine.

## Overview

- **OS:** NixOS 26.05 (unstable channel)
- **Desktop:** KDE Plasma 6 on Wayland (KWin), SDDM
- **Bootloader:** Limine
- **Terminal:** Konsole
- **Shell:** Zsh
- **Audio:** PipeWire
- **CPU:** AMD Ryzen 5 7535HS
- **GPU:** AMD Radeon 680M (iGPU, drives the internal panel) + NVIDIA RTX
  4050 Max-Q (dGPU, PRIME render offload only — run anything through it with
  `nvidia-offload <command>`)
- **Laptop control:** `asusctl` (fan curves, keyboard backlight, battery
  charge limit) + `supergfxctl` (dGPU power-state switching)

## Layout

| File | Contents |
|---|---|
| `configuration.nix` | Imports only |
| `hardware-configuration.nix` | Generated by `nixos-generate-config`, don't hand-edit |
| `modules/boot.nix` | Limine, kernel, zram/swap |
| `modules/networking.nix` | NetworkManager, firewall, DNS-over-TLS, MAC randomization |
| `modules/locale.nix` | Timezone, locale, console keymap |
| `modules/nix-settings.nix` | Nix features, GC, unfree |
| `modules/security.nix` | sysctl hardening, sudo, firejail, GnuPG, polkit |
| `modules/hardware.nix` | Hybrid graphics (PRIME offload), ASUS daemons, Bluetooth, I2C, RTL-SDR, webcam loopback, tablet, printing |
| `modules/power.nix` | Power profiles, lid/suspend behaviour, battery notes |
| `modules/audio.nix` | PipeWire |
| `modules/desktop.nix` | Plasma, SDDM, touchpad, fonts, theming |
| `modules/users.nix` | Account, shell, Steam, Flatpak |
| `modules/apps.nix` | Installed packages, nix-ld |
| `modules/default-apps.nix` | MIME associations |
| `modules/scripts.nix` | Custom scripts in `modules/scripts/` |

Small custom CLI helpers live in `modules/scripts/`: encrypted vault toggle,
metadata stripping, brightness control (kernel backlight or DDC/CI), Wi-Fi
hotspot, system telemetry, weather fetch.

## Differences from the desktop config

Everything outside hardware is kept identical on purpose. What differs:

- `modules/hardware.nix` — AMD iGPU + NVIDIA dGPU on PRIME offload with
  `asusd`/`supergfxd`, instead of the desktop's single NVIDIA card and
  OpenRGB motherboard lighting. Keyboard lighting is `asusctl aura` here.
- `modules/power.nix` — laptop-only module: power-profiles-daemon (Plasma's
  power profile switcher), lid-close behaviour, `powertop`/`acpi`.
- `modules/desktop.nix` — adds touchpad defaults and the Wayland/Ozone flag.
- `modules/boot.nix` — no `acpi_enforce_resources=lax`; ACPI owns the EC that
  `asusd` talks to on this machine.
- `modules/networking.nix` — firewall openings for the hotspot script's
  `ipv4.method shared` dnsmasq.
- `modules/security.nix` — `pinentry-qt` (Plasma) rather than the desktop's
  leftover `pinentry-rofi`.
